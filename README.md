# Shapechain 1.0 TEST
Native Java/Canvas Android 8+ Chained Block shape-uniqueness puzzle.

Shade tiles to form edge-connected dark blocks. Each block contains exactly one fixed-dark number giving its size. Blocks may have ANY shape. Corner-touching blocks form a chain; each block needs at least one corner neighbor. Every chain has no repeated shape, including rotated or reflected copies. Separate chains are allowed and may reuse shapes across chains. No rule requires rectangles, a single chain or a cycle. Tap blank tiles to shade or restore. Twelve unique 4x4 clue boards with twelve distinct solutions. All clues are numbered in this edition, no question marks.

Saved chain palette and shade marks, GG007 icon/menu/site/privacy, unlimited undo/reset. Offline, no ads, analytics, requested permissions or account. Settings and completion marks stay on device. External studio link opens browser.

Independent Java set-components, pairwise transform-and-fit shape comparisons and chain traversal check all 65536 masks per board against production bitset flood-fill and canonical eight-transform shape keys. Exactly one solution per board. Fixed-clue, bounds, toggle, solve, undo and replay pass. Adapter menu, settings, privacy, tile taps, next, levels and persistence pass. Actual drawing-code pixels inspected, not phone screenshots. Phone runtime, performance and browser handoff QA incomplete. Signed TEST only, not final or Play published.
